# VPN Management Panel

A comprehensive, production-ready VPN management system built with pure PHP and MySQL.

## Quick Start

This repository contains a complete VPN management system with admin and reseller dashboards.

**For installation instructions and full documentation, please see [VPN_README.md](VPN_README.md)**

## Features

- ✅ Auto-installation script
- ✅ Admin and reseller dashboards
- ✅ Multi-protocol VPN support (OpenVPN, SSH, WireGuard, IKEv2, SSTP)
- ✅ User and server management
- ✅ Invoice and payment system
- ✅ Reseller credit system
- ✅ Responsive design
- ✅ Secure authentication and CSRF protection

## Installation

1. Upload files to your web server
2. Navigate to `/install/`
3. Follow the installation wizard
4. Login to admin panel at `/admin/login.php`

## System Requirements

- PHP 7.4+
- MySQL 5.7+ / MariaDB 10.3+
- Apache/Nginx
- 512MB RAM minimum
- 1GB disk space

## Default Access

- Admin Panel: `/admin/login.php`
- Reseller Portal: `/reseller/login.php`
